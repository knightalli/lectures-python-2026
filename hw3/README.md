# Задание 1 

Файл [work1.py](work1.py).

В данном проекте реализована система учета рецептов. Используются 4 базовые коллекции Python.

- list хранит хронологию добавления рецептов - можем менять
- tuple фиксирует структуру рецепта (ID, название, категория, ингредиенты), обеспечивая неизменяемость данных в памяти. Представим, что нельзя менять рецепты.
- dict используется для соотношения Id и объекта для быстрого поиска за O(1).
- set автоматически поддерживает актуальный реестр уникальных категорий.
